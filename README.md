
# Smart Warehouse Inventory System

## Description

This project demonstrates generic programming in Python using the `typing` module.

Two case studies were completed:

### Activity 1
- Created a generic class called `Storage[T]`.
- Implemented:
  - `store()`
  - `retrieve()`
- Demonstrated the class using:
  - Integer
  - String
  - List

### Activity 2
Created a reusable warehouse inventory system using a generic class `Inventory[T]`.

The class can:
- Store items of any data type.
- Retrieve stored items.
- Display the type and value of stored items.
- Maintain multiple items while preserving generic type consistency.
